# 爱与我们：开源亲密关系笔记

用六个主题慢慢理解自己的相处方式：独立、空间、付出、沟通、吸引、选择。每个主题包含选择、自我判断和情境题，可跳过、分次填写，再查看整体总结、个人优点与需要调整的地方、逐项分析和具体行动。

这是独立的开源版本，不包含原网站的密钥、站点配置、浏览器记录或发布历史，也不会修改原网站。

## 三步使用

1. 安装 Node.js 22 或更高版本，下载本仓库并进入项目目录。
2. 在终端运行下面的命令，不需要安装运行时依赖。
3. 打开终端显示的本地网址，填写练习，再在分析页输入自己的 OpenAI API 密钥，勾选同意并生成分析。

```sh
npm start
```

本地网址默认是 `http://127.0.0.1:3000`。不要直接双击网页文件来调用接口。没有密钥时，问卷、本机简要整理与分享功能仍可使用。

## 密钥、费用与个人记录

- 本项目不附带公用密钥，后端也不会读取或回退使用站长的 `OPENAI_API_KEY`。
- 密钥只在当前页面内存中临时使用，不进入本地存储、会话存储、网址、分享内容或回答存档。可以随时点“清除密钥”，刷新或离开页面也会清除。
- 发起分析时，密钥和回答会经过当前部署的服务端，再由服务端请求 OpenAI 官方接口。本项目代码不持久保存或记录请求正文、密钥或回答；部署者的代理、监控等外部设施也应关闭正文记录。
- 使用别人部署的版本意味着需要信任其服务端；也可以自行部署，或者只运行在自己的电脑上。公开部署应使用 HTTPS。
- 回答和分析保存在当前浏览器中，采用独立的存储名称，不自动读取其他网站的记录。清除站点数据可能丢失这些记录。分享前可以预览，默认不带自由文本或智能分析。
- 费用和模型权限由填写者的 OpenAI API 账户决定。每次点击只发起一次请求，不自动重试，不使用原网站的全站每日额度。上游失败或取消后是否计费，以 OpenAI 实际账单为准。
- 请求使用 `store: false`，这不等于承诺 OpenAI 的所有数据保留机制均被关闭。可查看 [OpenAI 的数据说明](https://developers.openai.com/api/docs/guides/your-data)。

默认模型为 `gpt-6.1-sol`、高推理档；[模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol)列出了支持的推理档位。页面的模型设置允许填写账户有权使用、支持 Responses 接口和高推理的其他模型。权限不足会给出提示，不静默切换。密钥在 [OpenAI 平台](https://platform.openai.com/api-keys)管理；密钥保护方式可参考 [官方安全说明](https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety)。

## 自行部署

本地服务默认仅监听本机。部署到自己的 Node.js 服务器时，可显式设置 `HOST` 和 `PORT`。通过 HTTPS 反向代理公开访问时，还要设置 `PUBLIC_ORIGIN` 为完整的公开来源，例如 `https://你的域名`，不带路径，并让代理转发正确的 `Host` 和原始 `Origin` 请求头。服务不会盲目信任任意转发头。接口最多等待两分钟，代理超时也需要相应设置。不要开启请求正文日志。

也可以部署到自己的 Cloudflare Workers 账号：

```sh
npm run build
npx wrangler login
npx wrangler deploy
```

配置见 `wrangler.jsonc`，按需修改服务名称；不需要数据库、存储桶或站长 OpenAI 密钥。部署命令只操作你登录的账号。首次运行部署工具时会下载 Wrangler，相关配置见 [Cloudflare 官方文档](https://developers.cloudflare.com/workers/wrangler/configuration/)。

GitHub 公开仓库提供的是源码。GitHub Pages 只支持静态页面，不能运行这里的分析后端；完整功能请使用 Node.js 服务或 Workers。

## 验证与目录

```sh
npm test
```

自动检查使用虚构密钥与模拟响应，不产生 OpenAI 费用。上线后的真实可用性还取决于填写者的模型权限、余额和部署网络。

- `dist/`：中文界面、问卷、浏览器存档与分享逻辑。
- `worker/handler.template.js`：分析要求、密钥校验、官方接口请求及错误处理。
- `scripts/`：本地服务、构建与验证。
- `视频内容与题目依据.md`：内容来源与六个主题的设计依据。
